SIAB SYNTAX WEBSITE
====================

Open index.html in a browser.

Included:
- Vanilla HTML/CSS/JavaScript only — no React, Vite, Bootstrap or other framework.
- Supplied photo already placed at assets/afra.jpg.
- Responsive layout.
- Dark/light mode.
- Animated scroll reveals.
- Typewriter hero text.
- Cursor-controlled 3D laptop tilt.
- P1 and P2 note placeholders (10 chapters each).
- Note cards open PDFs in a new browser tab.

NOTES FOLDER SETUP
==================
The HTML expects these exact paths:

notes/P1/chapter-01.pdf
notes/P1/chapter-02.pdf
...
notes/P1/chapter-10.pdf

notes/P2/chapter-01.pdf
notes/P2/chapter-02.pdf
...
notes/P2/chapter-10.pdf

You can replace the placeholder folders/files with your real notes. If your PDFs have different names, edit the NOTES array near the bottom of index.html.

BEFORE DEPLOYMENT
=================
1. Replace 923000000000 with your real WhatsApp number.
2. Replace hello@siabsyntax.com if needed.
3. Update the YouTube URL if your channel URL differs.
4. If you want exact chapter names instead of "Chapter 01", edit the NOTES array.
5. Upload the whole folder while preserving the assets/ and notes/ structure.
